# Milpa Chef Tours

Ok let's make a website for food tours in Cholula coordinated by Milpa Chef. Please inspire yourself by the instagram account and logo https://www.instagram.com/milpachef/

Website should show:
- the agenda of the next available tours
-Allow users to reserve a spot on the planned tour
-Pay for it with a stripe integration
- it should show testimonials of the tour
-examples taken from instagram stories and feed.
-Be available in spanish, english and french
-be optimized for SEO and AI to find the webpage and be provided as option on what to do in cholula
